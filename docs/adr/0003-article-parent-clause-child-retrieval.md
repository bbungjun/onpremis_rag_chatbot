# 항으로 검색하고 조 전체를 답변 문맥으로 사용한다

상태: accepted. 직원 질문은 한 항의 기한·요건을 찾는 경우가 많지만, 답에는 같은 조의 적용 범위와 예외가 필요하다. 따라서 항을 검색용 단위로 임베딩하고, 선택된 항의 조 전체를 Qwen 문맥과 출처 단위로 사용한다. 고정 길이 분할은 조·항과 출처 경계를 끊을 수 있고, 조 전체만 색인하면 한 항의 표현이 긴 조 안에 묻힐 수 있다는 설계 판단이다. 이 청킹 방식 자체의 품질 우위는 별도 ablation으로 측정하지 않았다. 긴 조가 문맥 예산을 소진할 수 있고 원본 조를 각 항 payload에 반복하므로, 규모 증가 시 토큰 예산·저장량을 다시 측정해야 한다.
