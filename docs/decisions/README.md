# 의사결정 기록

2026-10-27 사용자 요청부터 중요한 기술·제품·평가·배포 판단을 작업 중 기록한다.
관련 작업의 최종 검증 결과까지 갱신하며, 이전 선택과 실패를 지우지 않는다.

각 기록은 관찰 → 대안 → 선택과 이유 → 검증 → 결과와 한계 → 다음 행동을 포함한다.
이는 판단의 근거와 실행 기록이며 비공개 사고 과정을 기록하는 문서가 아니다.
원문 정책, 자격증명, 환경변수 값 및 개인정보를 포함하지 않는다.

기록에는 별도 실험 브랜치에서 진행한 작업도 포함된다. 기록 문서가 main에
있다는 사실만으로 해당 구현까지 병합되거나 운영에 반영됐다고 해석하지 않는다.
각 기록의 소스 커밋·PR·검증 범위와 채택 상태를 함께 확인한다.
