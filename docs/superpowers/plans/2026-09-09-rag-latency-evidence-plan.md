# 별도 개선 과제: 품질을 지키는 로컬 RAG 지연 단축

상태: 계획 수립. 새 성능 실험·최적화·운영 승격은 실행하지 않았다.

## 목표

단순 설정 변경을 성과로 포장하지 않고, 관측된 병목에 맞는 RAG 개선을 선택해 동일 조건에서
평균/P95 E2E 지연 감소율을 측정한다. 관련 필수 사실·조건·예외·출처·무답 동작이 유지되는지
함께 확인한 결과만 이력서에 사용한다. 목표 감소율을 먼저 정하고 결과를 맞추지 않는다.

대략적인 관측은 출력 생성 비중이 크다는 것이다. 문맥 압축으로 큰 지연 감소가 날 것이라고
선결론 내리지 않는다. 입력 시간만 줄이는 변경은 출력 시간이 그대로면 효과가 제한될 수 있다.

## 1. 기준선과 성공 조건 고정

- 기존 qwen3:4b-instruct/think=off를 기준선으로 두고 모델·양자화·GPU·문서/질문 해시를 고정한다.
- 기존 데이터는 개발 자료로 취급한다. 후보 선택 전에 별도 확인 세트와 평가 기준을 고정하고,
  후보 조정 중에는 확인 세트의 결과를 열람하지 않는다.
- warm 응답과 cold start를 분리한다. GPU를 공유하는 앱의 상태, 동시 요청 수, context 및 출력
  예산을 기록한다. 먼저 1개 요청을 기준으로 계측하고 처리량은 별도 실험으로 둔다.
- 주 지표는 실제 E2E 완료 시간의 평균/P95. TTFT를 측정하면 별도 지표로 이름을 붙인다.
- 품질 기준은 필수 사실 누락, 문맥과 반대되는 판단, 근거 없는 허용/거절, 잘못된 출처와
  length 중단을 포함한다. EXAONE 평균 점수만으로 품질 유지 여부를 결정하지 않는다.

## 2. 병목 구간 확인 후 개입 하나 선택

| 실제로 큰 구간 | 검토할 개입 | 지켜야 할 품질 조건 |
| --- | --- | --- |
| 모델 로딩 | 서비스 수명/워밍업·적재 전략 | warm 개선과 cold 비용을 분리 보고 |
| 질문 임베딩·검색 | 실제 반복 질의가 있다면 캐시·검색 전략 | 문서 변경/권한 필터와 캐시 무효화 검증 |
| 입력 처리 | 질문과 관련된 근거를 보존하는 문맥 구성 | 조건·예외·출처가 잘려 나가지 않음 |
| 출력 생성 | 불필요한 반복·장황한 설명을 줄이는 답변 구성 | 필요한 정보량을 줄이거나 토큰 상한으로 자르지 않음 |

현재 관측상 출력 생성이 첫 진단 후보다. 답변 길이만 줄였다는 이유로 완료 처리하지 않는다.
예를 들어 질문이 요구하지 않은 조건을 만들어 미충족이라 단정하는 서술을 제거할 수 있는지,
필수 근거와 예외를 짧고 일관되게 전달할 수 있는지 확인한다. 이것은 아직 구현 아이디어다.

## 3. 개발 실험과 품질 확인

- 같은 검색 문맥에서 한 가지 개입의 효과를 먼저 분리한다. 문맥 구성 자체를 바꾸는 실험에서는
  동일 검색 후보를 고정하고 변경된 문맥/보존된 필수 근거를 기록한다.
- 답변의 필수 사실 체크리스트를 먼저 만든다. 현재 세션의 AI 검토는 잠정 검토로 표시하고,
  사람 또는 검증된 독립 평가와 대조하기 전 품질이 유지됐다는 결론을 내리지 않는다.
- 상대 기간, 경계값, 여러 요구사항, 문서에 없는 질문과 보안 관련 오류를 포함한다.
- 출력 토큰 수와 각 단계 duration을 비교해 지연 변화가 어디에서 생겼는지 설명한다.

## 4. 최종 E2E 대조 및 승격 판단

개발 후보가 품질 기준을 만족한 뒤 모델/환경/평가 질문을 고정하고 A/B 실행 순서를 교차한다.
예를 들어 50문항 x 2조건 x 3회는 300개 답변이다. 반복 3회를 150개 독립 질문으로 세지 않는다.
최종 표본 수와 반복 횟수는 예비 실행의 분산과 확인 세트 구성에 따라 결정한다.

원시 요청 단위 기록, 실패/중단, 모델 설정, 입력/출력 토큰, 단계별 시간, GPU/RAM 관측값을
보존한다. 배포할 후보가 동일 조건에서 지연을 줄이고 품질 게이트를 통과해야 승격한다.
통과하지 못하면 실패 결과를 남기고 기본값을 유지한다.

## 최종 이력서 문구의 형태 — 아직 사용 금지

> 로컬 사내 규정 RAG의 [검증된 병목]을 분석하고 [실제 구현한 변경]을 적용해,
> 동일 환경·확인 질문 N건에서 평균 E2E X초→Y초(Z%) 단축; [실제 품질 검증 결과] 확인.

Z = (X - Y) / X x 100. 평균/P95, warm/cold, 개발/확인 세트, 기준 모델과 실행 조건을 명시한다.
현재는 X/Y/Z가 새 통제 실험으로 측정되지 않았으며 이 문구는 성과가 아닌 목표다.
