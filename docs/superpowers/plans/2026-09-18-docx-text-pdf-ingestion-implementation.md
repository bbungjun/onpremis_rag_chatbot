# DOCX와 텍스트 PDF 수집 구현 계획 (2026-09-18)

1. 합성 규정 DOCX와 텍스트 PDF를 만들고 각 페이지를 렌더링해 글자·조항 순서를 확인한다.
2. DOCX/PDF 입력 거부, 텍스트 없는 PDF 실패, 동일 줄기 중복을 테스트로 재현한다.
3. 두 형식의 텍스트를 기존 구조화 Markdown과 조·항 청커에 연결한다. DOCX 단순 표의 열·값 관계를 확인한다.
4. HWP/HWPX와 1,000개 정책 단일 HWP의 파싱 회귀를 유지한다.
5. 전체 테스트·정적 검사·Docker 필수 명령·파일별 diff를 확인하고 포트폴리오 기록 후 PR을 연다.
