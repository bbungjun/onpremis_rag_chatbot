# HWP 조·항 파싱 보강 구현 계획 (2026-09-18)

1. 실제 HWP CLI 출력 형태인 인라인 조·항, `제N조의M`, 일부 조 누락을 실패 테스트로 먼저 재현한다.
2. HWP 정규화 어댑터와 구조 청커를 최소 변경으로 보강하고 기존 조 ID/출처 계약을 유지한다.
3. 작은 HWP 왕복과 단일 1,000개 정책 규정집의 구조 수·질문 대상 조를 다시 검증한다.
4. 전체 pytest/Ruff와 가능한 런타임 검증, 파일별 diff 및 `git diff --check`를 실행한다.
5. 포트폴리오 증거를 최종 결과로 갱신하고 기존 HWP PR을 push한다.
