# HWP 서식 내용 보존 파싱 구현 계획 (2026-09-18)

1. 표·번호 목록·각주·이미지가 함께 든 합성 HWP와 병합 표 HWP를 fixture로 고정하고, 현재 조 귀속/내용 손실을 실패 테스트로 재현한다.
2. 표의 열-값 관계, 병합 셀, 번호 목록의 순서, 각주 참조 귀속을 복원하는 순수 텍스트 보강 모듈을 구현한다.
3. HWP CLI가 추출한 이미지 자산을 로컬 OCR 인터페이스에 전달하고, OCR 실패가 무음 색인으로 이어지지 않게 한다.
4. 기존 1,000개 정책 단일 HWP가 조·항 수와 질문 매핑을 유지하는지 확인한다.
5. 전체 pytest/Ruff, Docker 필수 명령, 파일별 diff와 포트폴리오 증거를 마친 후 origin/main 대상 PR을 연다.
