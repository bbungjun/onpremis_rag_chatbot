# DOCX·PDF 합성 규정집 구현 계획 (2026-09-19)

1. 2정책으로 두 파일을 생성·재추출하고 조·항·질문 매핑을 비교하는 실패 테스트를 작성한다.
2. 한 원문을 DOCX 문단·제목 스타일과 PDF 텍스트 페이지에 배치하는 생성기를 구현한다.
3. 정책 1,000개를 DOCX/PDF 각 1권으로 생성하고 해시·용량·페이지·조항·답 문구를 검증한다.
4. PDF 페이지를 렌더링해 시각 검사하고 DOCX 렌더 가능 여부를 확인한다. 불가능한 검증은 측정하지 않음으로 기록한다.
5. 전체 pytest/Ruff, Docker 필수 명령, 파일별 diff와 포트폴리오 증거를 마친 뒤 PR을 열고 병합 상태를 확인한다.
