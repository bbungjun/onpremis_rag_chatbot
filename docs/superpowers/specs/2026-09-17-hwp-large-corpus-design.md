# HWP 대규모 규정 코퍼스 설계 (2026-09-17)

## Before / 문제

현재 검색 코퍼스는 합성 Markdown 규정집 1개(207,536바이트, 100개 조, 검색용 child 600개)다. 수집기는 `*.md`만 읽고 구조화 Markdown 표기를 전제로 청킹한다. 대량의 `.hwp` 문서를 입력하면 읽을 수 없으며, 한 문서 전체의 포인트를 메모리에 모아 한 번에 업로드한다. 서로 다른 문서에 같은 `제1조`가 있을 때 질의 단계의 parent 중복 제거가 `parent_id`만 사용하여 한 문서를 누락시킬 수 있다.

## 목표와 범위

- 사내 규정처럼 보이는 **합성** HWP 5.0 바이너리 문서를 결정적으로 생성한다. 파일 수는 인자로 지정하며 기본 실험 목표는 1,000개다. 생성물은 로컬 `reports/hwp-large-corpus/`에 두고 Git에는 생성기와 검증 코드만 추적한다.
- `.hwp`와 기존 `.md`를 같은 수집 CLI에서 색인한다. 문서 출처와 조/항 구조를 유지한다.
- HWP 추출 실패나 조/항 미검출은 조용히 건너뛰지 않고 실패로 보고한다.
- 메모리에 전체 포인트를 쌓지 않고 유한한 배치로 Qdrant에 적재한다.
- 서로 다른 문서의 같은 조 번호를 별개 근거로 취급한다.
- 기존 로컬 Ollama/Qwen, dense + sparse + RRF, Qdrant 구조는 유지한다.

## Why / 설계

HWP 5.0은 바이너리 형식이므로 텍스트 파일처럼 디코딩할 수 없다. 포맷 변환 책임을 HWP CLI 어댑터 한곳에 둔다. `hwp-cli` v0.17.0의 `new --from`과 `cat --format markdown`을 사용하고 버전 및 바이너리 SHA-256을 고정한다. 이 도구는 Apache-2.0이며 Windows/Linux 실행 파일을 제공한다. 추출 결과의 자동 제목 번호를 기존 청커가 인식하는 편/장/절/조/항 Markdown으로 정규화한다. 이 어댑터의 출력이 청킹 모듈의 입력 인터페이스다.

대규모 실험의 파일 수만 늘리기 위해 동일 규정을 복제하지 않는다. 주제, 업무 상황, 적용 조직, 절차와 숫자 조건을 결정적 규칙으로 조합한다. 합성 데이터는 실제 회사 규정이나 현업 정확도 증거로 표현하지 않는다. 같은 생성기에서 산출한 질의는 독립 홀드아웃이 아니므로 검색 회귀 확인용으로만 사용한다.

## 데이터 흐름

`합성 정책 사양 → Markdown 중간 산출물 → HWP CLI → .hwp → HWP CLI 추출 → 구조 정규화 → parent/child 청킹 → 로컬 bge-m3·kiwipiepy → Qdrant 배치 업서트 → RRF 검색 → 문서별 parent 확장 → Qwen`

생성용 Markdown 중간 산출물은 `reports/`에만 둔다. 문서 ID는 상대 경로에 기반하고 Qdrant 포인트 ID는 문서 ID와 청크 ID의 조합으로 생성한다. 검색된 parent의 중복 제거 키는 문서 ID/출처와 parent ID의 조합이다.

## 대안과 한계

- `pyhwp`의 텍스트 변환은 실험적이며 공개 배포판의 Python 지원 범위가 현재 Docker Python 3.11보다 오래되었다. 이번 구현에는 넣지 않는다.
- HWPX 직접 XML 파싱은 생성 대상인 `.hwp` 바이너리를 검증하지 못한다.
- 변환과 추출에 동일한 CLI를 쓰는 왕복 검사는 두 구현이 공유하는 오류를 놓칠 수 있다. 별도 뷰어 확인과 실제 HWP 샘플 검증은 후속 실험이다.
- 표, 그림, 암호화/DRM, 자동 번호, 각주 등은 대표 샘플별로 별도 검증해야 한다. 이번 합성 코퍼스는 텍스트 중심 구조 부하 시험이다.

## 검증 기준

- 테스트: HWP 변환 실패, 빈/비구조 추출, 자동 번호 정규화, 배치 적재, 문서 간 parent 충돌을 재현하고 수정한다.
- 생성 실험: 파일 수/총 바이트/추출된 조·항 수, 생성 실패, 왕복 텍스트 누락을 기록한다.
- 런타임: Docker 가용 시 전체 pytest, Qdrant 상태, healthcheck, 색인 및 검색의 시간·RAM·디스크·검색 품질을 동일 조건에서 측정한다. 불가하면 미측정으로 기록한다.
